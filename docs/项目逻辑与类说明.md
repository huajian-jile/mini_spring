# Minispring 项目逻辑与类说明

## 一、项目整体逻辑

### 1.1 启动流程（refresh）

```
Application.main
  → MySpringApplication.run(Application.class)
  → MyApplicationContext.refresh(appClass)
      ① initDataSource()               — 初始化数据源
      ② scanPackage(packageName)       — 扫描包下所有 .class，得到 Class 列表
      ③ initAop(classes)               — 解析 @Aspect，注册切面实例与顾问列表（@Before/@After/@Around 等）
      ④ registerBeanDefinitions(classes) — 只注册 Bean 定义（Mapper / 组件），不创建实例；切面类不注册为 Bean
      ⑤ registerProcessorsAndSingletons() — 注册 AopBeanPostProcessor、SqlSession 等单例
      ⑥ beanFactory.preInstantiateSingletons() — 按定义创建所有单例 Bean（含依赖注入、BeanPostProcessor、AOP 代理）
      ⑦ initHandlerMapping()          — 建立 URL → Handler(Controller, Method) 映射
      ⑧ startServer()                 — 启动 HTTP 服务（端口 8099）
```

### 1.2 IOC 与 AOP 如何协作

- **IOC**：负责扫描、注册 Bean 定义、实例化 Bean、属性注入（@Autowired）、单例缓存；通过 `BeanPostProcessor` 扩展生命周期。
- **AOP**：以 `BeanPostProcessor` 身份介入：在 Bean 初始化**之后**（`postProcessAfterInitialization`），对需要代理的 Bean 用 JDK 动态代理或 CGLIB 生成代理并返回代理对象；代理在方法调用时通过 `AopAdvisorRegistry` 取拦截器链，经 `ReflectiveMethodInvocation` 依次执行拦截器并最终调用目标方法。
- **顺序**：先有 Bean 定义与创建流程（IOC），再在创建后对符合条件的 Bean 做 AOP 包装；路由与 HTTP 使用的是已包装后的 Bean（可能已是代理）。

## 二、IOC 相关目录与类说明

IOC 相关类位于 **`liu.spring.ioc`** 包，注解在 **`liu.spring.annotation.spring.ioc`**。

### 2.1 核心容器（liu.spring.ioc）

| 类名 | 职责 |
|------|------|
| **MyApplicationContext** | 应用上下文入口。负责：包扫描、AOP 初始化、Bean 定义注册、后置处理器与单例注册、预实例化、Handler 映射、启动 HTTP 服务；对外提供 `getBean(name/type)`。 |
| **BeanFactory** | Bean 工厂接口。定义 `getBean`、`getBeanByType`、`containsBean` 等，由 DefaultListableBeanFactory 实现。 |
| **BeanDefinition** | Bean 元数据：beanName、beanClass、scope、lazy、mapper、aspect、componentAnnotation 等。 |
| **BeanDefinitionRegistry** | Bean 定义注册表接口。注册/获取/是否包含/获取所有名称，由 DefaultListableBeanFactory 实现。 |
| **DefaultListableBeanFactory** | 默认 Bean 工厂实现。持有 Bean 定义、单例缓存、正在创建集合、BeanPostProcessor 列表；实现 `doGetBean`、依赖注入、调用 BeanPostProcessor 前置/后置、Mapper 代理创建等。 |
| **BeanPostProcessor** | Bean 后置处理器接口。`postProcessAfterInitialization` 在 Bean 初始化后被调用，用于扩展（如 AOP 包装）。 |
| **ComponentAnnotationRegistry** | 组件注解注册表。维护“哪些注解算组件”（如 @Component、@Service、@Controller、@RestController）；提供 `isComponent`、`getSuggestedBeanName` 等，扫描时据此判断是否注册为 Bean。 |

### 2.2 IOC 注解（liu.spring.annotation.spring.ioc）

| 注解 | 职责 |
|------|------|
| **SpringBootApplication** | 标记启动类。 |
| **Component** | 通用组件，可指定 value 作为 Bean 名。 |
| **Service** | 服务层组件。 |
| **Controller** | 控制层组件。 |
| **RestController** | REST 控制层（与 @Controller 一样被识别为组件）。 |
| **Mapper** | Mapper 接口，注册为 Bean 定义，由工厂创建 JDK 代理。 |
| **Autowired** | 字段注入，按类型从容器取 Bean 并注入；也可标在构造器上做构造器注入。 |
| **Qualifier** | 按名称限定：存在多个同类型 Bean 时，指定要注入的 Bean 名称（value）。 |
| **Value** | 简单值注入。格式 `${key}` 或 `${key:default}`，由 propertySources 解析；支持 String、int、long、boolean、double 等类型。 |
| **PostConstruct** | 生命周期回调：依赖注入完成后、Bean 使用前执行，标注在无参方法上。 |

**IOC 其它能力**：单例/原型作用域（prototype 每次 getBean 新建）、懒加载（lazy 的 Bean 首次 get 才创建）、按类型查找多候选时抛异常并提示使用 @Qualifier、BeanPostProcessor 实现 `Ordered` 接口可指定执行顺序（`getOrder()` 越小越先执行）。

## 三、AOP 相关目录与类说明

AOP 相关类位于 **`liu.spring.container.aop`**（拦截器、注册中心等）及 **`liu.spring.container`** 中的 AopBeanPostProcessor、AopProxyHandler、CglibAopProxy；注解在 **`liu.spring.annotation.spring.aop`**；切点匹配与示例切面在 **`liu.spring.aspect.logaspect`**。

### 3.1 代理与注册（liu.spring.container + liu.spring.container.aop）

| 类名 | 职责 |
|------|------|
| **AopBeanPostProcessor** | AOP 的 Bean 后置处理器；实现 `Ordered`，默认 LOWEST_PRECEDENCE。在 `postProcessAfterInitialization` 中判断 Bean 是否需要代理（needsProxy）；需要则用 JDK 动态代理（有接口）或 CGLIB（无接口）创建代理并返回。 |
| **AopContext** | 暴露当前 AOP 代理。在代理方法内通过 `AopContext.currentProxy()` 获取当前代理对象，用于自调用时仍走切面；代理调用前后由 AopProxyHandler/CglibAopProxy 设置与清除 ThreadLocal。 |
| **AopProxyHandler** | JDK 动态代理的 InvocationHandler。对 Object 方法做短路；对业务方法取拦截器链，封装为 ReflectiveMethodInvocation 并 proceed，最后解包 InvocationTargetException。 |
| **CglibAopProxy** | CGLIB 子类代理。实现 cglib 的 MethodInterceptor，在 intercept 中取拦截器链并执行 ReflectiveMethodInvocation；无接口 Bean 的 AOP 由此实现。 |
| **AopAdvisorRegistry** | AOP 顾问注册中心。维护：方法注解 → 拦截器（及 order）、切点顾问列表（PointcutAdvisorEntry）；提供 `getInterceptors(target, method)` 构建排序后的拦截器链，`needsProxy(targetClass)` 判断类是否需要代理。 |
| **PointcutAdvisorEntry** | 单条切点顾问：切点表达式、通知方法、通知类型（BEFORE/AFTER/AROUND 等）、order。 |

### 3.2 拦截器链（liu.spring.container.aop）

| 类名 | 职责 |
|------|------|
| **MethodInterceptor** | 方法拦截器接口。`invoke(MethodInvocation invocation)`，内部可调用 `invocation.proceed()` 继续链或执行目标方法。 |
| **MethodInvocation** | 方法调用上下文接口。提供 `getTarget/getMethod/getArguments` 和 `proceed()`。 |
| **ReflectiveMethodInvocation** | 反射实现的 MethodInvocation。持有一条 MethodInterceptor 列表和当前下标，`proceed()` 时先执行下一个拦截器，无则反射调用目标方法。 |
| **AspectMethodInterceptor** | 将实现 Advice 接口的切面适配为拦截器。执行 before → proceed → after；异常时 afterThrowing，保证链不断。 |
| **AspectBeforeMethodInterceptor** | @Before 切面方法适配器。先反射执行切面方法（before），再 proceed。 |
| **AspectAfterMethodInterceptor** | @After 切面方法适配器。先 proceed，在 finally 中执行切面方法（after）。 |
| **AspectAfterReturningMethodInterceptor** | @AfterReturning 适配器。proceed 后若正常返回，再执行切面方法（带 result）。 |
| **AspectAfterThrowingMethodInterceptor** | @AfterThrowing 适配器。proceed 抛异常时执行切面方法（带 Throwable）后继续抛出。 |
| **LogMethodInterceptor** | 对带 @Log 的方法做日志增强（前后打印参数/返回值等）。 |
| **ExecutionTimeMethodInterceptor** | 对带 @ExecutionTime 的方法做耗时统计。 |
| **PrintCurrentTimeMethodInterceptor** | 对带 @PrintCurrentTime 的方法在调用前后打印当前时间。 |
| **AspectInvocationHelper** | 反射调用切面方法，支持 (target, method, args)、(target, method, args, result)、(target, method, args, throwable) 等常见签名。 |

### 3.3 顺序与类型（liu.spring.container.aop）

| 类名 | 职责 |
|------|------|
| **Ordered** | 顺序常量接口。HIGHEST_PRECEDENCE / LOWEST_PRECEDENCE。 |
| **OrderedAdapter** | 带顺序的拦截器标记接口。`getOrder()` 用于链排序。 |
| **AdviceType** | 通知类型枚举：BEFORE、AFTER、AFTER_RETURNING、AFTER_THROWING、AROUND。 |

### 3.4 切点匹配与切面示例（liu.spring.aspect.logaspect）

| 类名 | 职责 |
|------|------|
| **PointcutMatcher** | 切点表达式匹配。支持类级与方法级：execution、包通配、@annotation 等；`matches(expression, targetClass, method)` 用于顾问链构建与 needsProxy。 |
| **LogAspect** | 示例切面类。实现 Advice，@Around("liu.service.*")，演示 before/after/afterThrowing/around。 |

### 3.5 AOP 注解（liu.spring.annotation.spring.aop）

| 注解 | 职责 |
|------|------|
| **Aspect** | 标记切面类。 |
| **Order** | 切面/顾问执行顺序，value 越小越先执行。 |
| **Around** | 环绕通知，value 为切点表达式。 |
| **Before** | 前置通知，value 为切点表达式。 |
| **After** | 后置通知（finally 型），value 为切点表达式。 |
| **AfterReturning** | 返回通知，value 为切点表达式。 |
| **AfterThrowing** | 异常通知，value 为切点表达式。 |
| **Advice** | 通知接口。定义 before/after/afterThrowing/around 默认实现。 |
| **Log** | 方法级日志增强，可配置描述、是否打印参数/返回值。 |
| **ExecutionTime** | 方法级耗时统计，可配置阈值。 |
| **PrintCurrentTime** | 方法级打印当前时间，可配置前后、格式。 |
| **Pointcut** | 切点注解（本项目中未在运行时使用）。 |

## 四、其他模块

### 4.1 Web MVC（liu.spring.webmvc + liu.spring.annotation.web）

与 Spring MVC 对齐：前端控制器 + HandlerMapping + HandlerAdapter + 参数/返回值处理。

| 类/接口 | 职责 |
|--------|------|
| **DispatcherServlet** | 前端控制器，实现 HttpHandler。按请求从 HandlerMapping 取 HandlerExecutionChain，用 HandlerAdapter 执行并写响应。 |
| **HandlerMapping** | 接口：根据 NativeWebRequest 返回 HandlerExecutionChain。 |
| **RequestMappingHandlerMapping** | 实现：扫描 @Controller/@RestController 的 @RequestMapping、@GetMapping、@PostMapping，支持路径变量如 /user/{id}、同一路径多方法（GET/POST）。 |
| **HandlerMethod** | 封装 (bean, method, pathPattern, httpMethods)，路径模式可含 {name}，匹配时提取 path variable。 |
| **HandlerExecutionChain** | 封装 handler + 可选拦截器列表。 |
| **HandlerAdapter** | 接口：supports(handler)、handle(request, handler) -> ModelAndView。 |
| **RequestMappingHandlerAdapter** | 实现：解析 @RequestParam、@PathVariable、@RequestBody、注入 NativeWebRequest/HttpExchange，调用方法；对 @ResponseBody / @RestController 返回值序列化为 JSON 写回。 |
| **NativeWebRequest** | 对 HttpExchange 的封装，提供 getPath()、getMethod()、getParameter(name)、getPathVariables()、getBodyAsString()。 |
| **ModelAndView** | 模型 + 视图名（当前 REST 场景下由 Adapter 直接写响应，可为 null）。 |
| **JsonUtils** | 简单 JSON 序列化/反序列化（无第三方依赖），供 @RequestBody/@ResponseBody 使用。 |

**Web 注解**（liu.spring.annotation.web）：

| 注解 | 职责 |
|------|------|
| **RequestMapping** | value=路径，method=HTTP 方法数组（可选）。 |
| **GetMapping / PostMapping** | 继承 RequestMapping，限定 GET/POST。 |
| **RestController** | 组合 @Controller + 语义上等价于类上 @ResponseBody。 |
| **RequestParam** | 绑定查询参数，支持 name、required、defaultValue。 |
| **PathVariable** | 绑定路径变量，如 /user/{id} 的 id。 |
| **RequestBody** | 绑定请求体（JSON 解析为 Map/List/String）。 |
| **ResponseBody** | 方法返回值直接写回响应体（JSON）。 |
