# MiniSpring 项目说明

## 一、项目概述

**MiniSpring** 是一个轻量级的 Java 学习/教学项目，仿照 Spring Boot + MyBatis 的核心架构，从零实现了一个精简版的 **SSM（Spring + Spring MVC + MyBatis）** 框架。通过造轮子的方式，帮助开发者深入理解 Spring 家族框架的工作原理。

> 正如项目中的一句话：**「不会造轮子和会，不想造是两回事。」**

---

## 二、核心功能

### 1. IoC 容器（控制反转）

- **包扫描**：自动扫描启动类所在包及其子包下的所有类
- **Bean 管理**：支持 `@Component`、`@Service`、`@Controller` 等注解标注的组件自动实例化并放入容器
- **依赖注入**：通过 `@Autowired` 自动注入依赖，支持两次注入机制以正确处理 AOP 代理对象

### 2. AOP（面向切面编程）

- **注解驱动**：
  - `@Log`：自动记录方法调用、参数和返回值
  - `@ExecutionTime`：统计并打印方法执行耗时，支持阈值过滤
- **切面配置**：`@Aspect` + `@Around` 实现自定义切面，如 `LogAspect` 拦截 service 包下的所有方法
- **代理机制**：使用 JDK 动态代理，对实现了接口的 Bean 创建代理对象，确保 Controller 调用 Service 时能正确触发 AOP 逻辑

### 3. Web 层（类似 Spring MVC）

- **注解路由**：`@RestController`、`@RequestMapping`、`@GetMapping`、`@PostMapping`
- **HTTP 服务器**：基于 JDK 内置 `HttpServer` 监听端口 8099
- **请求分发**：根据 URL 映射到对应的 Controller 方法并执行

### 4. 持久层（类似 MyBatis）

- **Mapper 接口**：通过 `@Mapper` 标注接口，无需手写实现类
- **SQL 注解**：`@Select`、`@Insert`、`@Update`、`@Delete` 声明 SQL 语句
- **代理实现**：`SqlSession.getMapper()` 使用 JDK 动态代理，在运行时根据注解解析并执行 SQL

## 三、项目结构

```
src/liu/
├── Application.java              # 启动类，@SpringBootApplication
├── annotation/                   # 自定义注解
│   ├── spring/
│   │   ├── ioc/                  # IoC 相关：SpringBootApplication, Component, Service, Controller, Autowired, Mapper
│   │   └── aop/                  # AOP 相关：Aspect, Around, Advice, Log, ExecutionTime, Pointcut
│   ├── web/                      # Web 相关：RestController, RequestMapping, GetMapping, PostMapping
│   └── mybatis/                  # 持久层：Select, Insert, Update, Delete
├── aspect/logaspect/             # 切面实现
│   ├── LogAspect.java            # 日志切面
│   └── PointcutMatcher.java      # 切点表达式匹配器
├── container/                    # 核心容器
│   ├── MyApplicationContext.java # IoC 容器，负责扫描、实例化、注入、AOP、路由、启动服务
│   └── AopProxyHandler.java      # AOP 动态代理处理器
├── Controller/                   # 控制器层
├── service/                      # 业务层
├── mapper/                       # 数据访问层
├── db/                           # 数据库
│   ├── SqlSession.java           # Mapper 代理创建与 SQL 执行
│   └── MyDataSource.java         # 数据源
└── util/                         # 工具类
    ├── MySpringApplication.java  # 启动入口
    └── Handler.java              # 请求处理器封装
```

## 四、容器启动流程

```
1. 扫描包          → 获取启动类包下所有 .class 文件
2. 初始化 AOP      → 注册 @Aspect 切面类和 @Around 切点
3. 实例化 Bean     → 创建 Component/Service/Controller/Mapper 实例
4. 第一次依赖注入  → 注入原始对象，建立引用关系
5. 创建 AOP 代理   → 对匹配切点或带 @Log/@ExecutionTime 的 Bean 生成代理
6. 第二次依赖注入  → 将引用更新为代理对象（确保 Controller 持有的是代理）
7. 建立路由映射    → 扫描 Controller，注册 URL -> Handler
8. 启动 HTTP 服务  → 监听 8099 端口
```

## 五、使用示例

### 启动应用

```java
@SpringBootApplication
public class Application {
    public static void main(String[] args) throws Exception {
        MyApplicationContext context = MySpringApplication.run(Application.class);
        System.out.println("项目启动成功");

        IUserService userService = (IUserService) context.getBean("userServiceImp");
        userService.getAllUsers();
    }
}
```

### Controller 示例

```java
@RestController
@RequestMapping("/user")
public class UserController {
    @Autowired
    public IUserService userService;

    @GetMapping("/list")
    @Log(value = "查询用户列表接口", printArgs = false, printResult = true)
    @ExecutionTime(value = "用户列表查询", threshold = 0)
    public List<Map<String, Object>> listUsers() {
        return userService.getAllUsers();
    }
}
```

### Service 示例

```java
@Service
public class UserServiceImp implements IUserService {
    @Autowired
    private UserMapper userMapper;

    @Override
    @Log("日志打印：数据库开始查询")
    @ExecutionTime(value = "数据库查询用户", threshold = 50)
    public List<Map<String, Object>> getAllUsers() {
        return userMapper.findAll();
    }
}
```

### Mapper 示例

```java
@Mapper
public interface UserMapper {
    @Select("SELECT * FROM textmybatis")
    List<Map<String, Object>> findAll();
}
```

## 六、技术要点

| 模块 | 实现方式 |
|------|----------|
| 包扫描 | ClassLoader + 文件系统遍历 |
| 依赖注入 | 反射 `Field.set()` |
| Mapper 代理 | `Proxy.newProxyInstance` + `InvocationHandler` |
| AOP 代理 | JDK 动态代理 + `AopProxyHandler` |
| Web 服务 | JDK `HttpServer` |
| 路由匹配 | 注解解析 + HashMap 映射 |
